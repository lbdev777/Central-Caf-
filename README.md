# Central Café Rimouski — maquette de refonte

Proposition de refonte du site du [Central Café](https://centralcaferimouski.com/), préparée par Studio Atlas. Ce n'est pas le site officiel du restaurant.

Le contenu (menu d'avril 2026, histoire, heures, boutique) et les photos sont repris du site actuel.

- `index.html` : la page complète, sans dépendance à installer
- `images/` : les photos, logos et icônes du site
